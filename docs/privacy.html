Privacy Policy

This application (“AI Video Pipeline”) is operated by the owner of the connected YouTube, Facebook and Instagram accounts (the “operator”).

Data we access

  • Google / YouTube: with the operator's authorization, the app uploads videos to the operator's own YouTube channel (scope youtube.upload) and may read public statistics (views, likes, comments counts) of videos it uploaded.
  • Meta (Facebook/Instagram): with the operator's authorization, the app publishes Reels to the operator's own Page and Instagram professional account.
  • Public sources: GitHub, arXiv, Hacker News, Hugging Face and public RSS feeds, used only for public metadata about projects and news.

Data we do not collect

The app does not collect, store or sell personal data of visitors or viewers. It has no sign-up, tracking, cookies or advertising.

Storage and security

OAuth tokens are kept as encrypted GitHub Actions secrets and are never published. The pipeline database contains only public project/news metadata and video publishing records.

Sharing

Data is sent only to the official APIs of the platforms named above, and to Anthropic's API (script text built from public metadata) when script rewriting is enabled. We do not sell or share data with anyone else.

Google API Services

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

The operator can revoke access at any time at myaccount.google.com/permissions and in Facebook/Instagram business integration settings, and can delete stored tokens by removing the repository secrets.
