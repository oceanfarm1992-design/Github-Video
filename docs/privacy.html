Privacy Policy

This application (“AI Video Pipeline”) is operated by the owner of the connected YouTube, Facebook and Instagram accounts (the “operator”).

Data we access

  • Google / YouTube: with the operator's authorization, the app uploads videos to the operator's own YouTube channel (scopes youtube.upload, youtube.readonly and youtube.force-ssl to read and reply to comments on the operator's own videos) and may read public statistics (views, likes, comments counts) of videos it uploaded.
  • Meta (Facebook/Instagram): with the operator's authorization, the app publishes Reels to the operator's own Page and Instagram professional account.
  • Public sources: GitHub, arXiv, Hacker News, Hugging Face and public RSS feeds, used only for public metadata about projects and news.

Comments on our videos

To answer comments automatically, the app reads comments left on the operator's own videos (YouTube, Facebook, Instagram) through the platforms' official APIs, including the commenter's public name and ID and the comment text. Comments that are not spam may be answered publicly or, when the viewer comments the requested keyword, by a direct message containing the requested link.

These comment records are kept in a private database (Supabase) to avoid answering the same person twice, and are never published. Comment text is sent to Anthropic's API only to draft a short reply, and is not stored with the drafted reply in any public place. The app does not sell personal data, and has no sign-up, tracking cookies or advertising.

Storage and security

OAuth tokens are kept as encrypted GitHub Actions secrets and are never published. The public pipeline database contains only public project/news metadata and video publishing records; comment data is kept only in the private database described above.

Sharing

Data is sent only to the official APIs of the platforms named above, to Zernio (a publishing service that calls Facebook and Instagram on the operator's behalf), and to Anthropic's API (script text built from public metadata, and comment text to draft replies). We do not sell or share data with anyone else.

Google API Services

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

The operator can revoke access at any time at myaccount.google.com/permissions and in Facebook/Instagram business integration settings, and can delete stored tokens by removing the repository secrets.
